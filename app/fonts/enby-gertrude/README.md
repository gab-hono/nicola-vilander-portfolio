# Enby Gertrude

Typeface used for headings, work titles and Nícola's name in text form.

- Design: Valentin Chauveau and Léna Salabert-Triby (2021–2024), with a set of non-binary ligatures drawn in workshops with Collletttivo and the Bye Bye Binary collective. Its completion was commissioned by the Théâtre National Wallonie-Bruxelles for the visual identity of the Maison Gertrude art centre, hence its name.
- Source: [Bye Bye Binary type library](https://typotheque.genderfluid.space)
- Licence: CUTE (Conditions d'utilisations typographiques engageantes), see `2024_BBB_CUTE_FR.pdf` in this folder.
- File: `Enby_Gertrude_roman.woff2` from `webfonts/woff2/`, unmodified and not subset, so every post-binary ligature and OpenType feature is kept, as CUTE requires. The family has a single style (roman, regular weight): do not add `italic` or bold utilities to `font-serif` text, the browser would fake them.
