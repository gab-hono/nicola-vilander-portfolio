# BBB Baskervvol

Typeface used for headings, titles and Nícola's name in text form.

- Source: [Bye Bye Binary type library](https://typotheque.genderfluid.space/fr/fontes/baskervvol) · [GitLab](https://gitlab.com/bye-bye-binary/baskervvol)
- Licence: CUTE (Conditions d'utilisations typographiques engageantes), see `2024_BBB_CUTE-EN.pdf` and `2024_BBB_CUTE_FR.pdf` in this folder.
- Files: the two variable webfonts (upright and italic, `wght` 400–800) from `variable/webfonts/`, unmodified and not subset, so every post-binary glyph and OpenType feature is kept, as CUTE requires.

## Credits

BBB Baskervvol is Bye Bye Binary's version of the ANRT's Baskervville, itself a revival of Claude Jacob's 1784 Baskerville.
